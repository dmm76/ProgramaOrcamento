# 💼 Programa Orçamento

Sistema de geração de orçamentos comerciais desenvolvido em Java com banco de dados MySQL. Este projeto foi criado como parte da conclusão do curso Técnico em Desenvolvimento de Sistemas no Senai.

## 🛠 Tecnologias Utilizadas

- Java
- MySQL
- JDBC
- Swing (para interface gráfica, se aplicável)
- Estrutura de diretórios modularizada
